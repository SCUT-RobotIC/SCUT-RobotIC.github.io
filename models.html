glTF · WebGL

模型来自实验室当年的 SolidWorks 装配体，导出后统一转换与压缩，只保留可视化几何 —— 不包含装配约束、参数化特征与工程图，因此只能看、不能拆装。

Pipeline

模型是怎么上网页的

浏览器读不了 SLDPRT / SLDASM（SolidWorks 私有格式），所以必须先导出一次中性格式。

SolidWorks 导出

打开当年总装 → 另存为 STEP（保留颜色）或 STL / 3MF（更轻，单色）。

转成 glTF

python tools/cad_to_glb.py 把 URDF 包 / 网格 / STEP 转成 .glb，并按关节位姿装配。

压到网页友好

抽稀到目标面数、去掉重复顶点、统一成米制与 Y 轴向上，单个模型控制在 3–8 MB。

挂到清单

在 assets/models/manifest.json 里加一行，页面自动出现新的模型标签。
